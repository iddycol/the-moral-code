# Core-12 external provenance audit

These are researcher-facing records, not evaluator input. Do not load them into a masked trial: titles, URLs, identities, outcome references and reviewer judgments can reveal the historical answer. Original v0.1.3 packets and outputs remain unchanged.

All **80 action evidence claims** are covered exactly once, with exact frozen wording. Their audit classifications are **38 supported, 19 partially supported, 21 inference and 2 unverified_access**. These are source-review classifications, not morality scores, probabilities or automatic confidence assignments. Supported does not certify decision-time availability. Inference does not mean false; it identifies the need to separate reasoning from observation. Access failure does not imply falsity.

Both Repair cases have **38 audit rows** covering all **nine established-harm entries**, all **19 repair options**, seven additional premises and three option subclaims. Their audit units differ from action evidence, so do not pool those status counts into an accuracy score.

Each ledger contains its own source registry, locators, access outcomes, support notes and temporal limitations. The review uses primary documents where readable and explicitly identifies institutional reconstruction, archive catalogue descriptions or an unverified transcription where those are all that could be inspected. A full original-document authentication audit is not claimed. Source websites and availability can change after this audit date, 19 September 2026.

[coverage.json](coverage.json) was generated by [check_coverage.py](check_coverage.py). The check verifies uniqueness, complete action coverage, exact frozen claim text, and exact text/coverage for all Repair harms and option descriptions. It does not prove source support. [frozen-input-audit.json](frozen-input-audit.json), generated by [check_frozen_inputs.py](check_frozen_inputs.py), reproduces the missing-link counts and five explicit identity disclosures across four full inputs.

From repository root:

```text
python docs/evidence/core12-provenance-10/check_coverage.py
python docs/evidence/core12-provenance-10/check_frozen_inputs.py
```

The scripts only read frozen data and print findings. They make no evaluator or network calls. The full frozen loader was also run at publication preparation to check the canonical digest and 29 source hashes; no source suite rerun is needed for these documentation and read-only audit additions.
