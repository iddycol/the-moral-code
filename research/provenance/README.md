# Provenance Method

## Purpose

The provenance ledger tests whether the Moral Code is genuinely defensible across diverse moral traditions, or merely a plausible contemporary synthesis dressed up as universality.

The aim is **not** to prove that every tradition contains every Moral Code principle. They do not.

For each principle we ask:

1. **Support** — where does a materially similar idea recur?
2. **Grounding** — why does the source/tradition think the idea is true?
3. **Scope** — to whom or what does the principle apply?
4. **Contradiction** — where does the same tradition contain or historically support an incompatible rule or practice?
5. **Interpretive dispute** — where do serious readers disagree about what the source means?
6. **Cultural challenge** — does the Moral Code assume a specifically modern, liberal, Western or individualist conception?
7. **Hard cases** — where does the principle collide with another principle?
8. **Amendment consequence** — does the evidence support retaining, narrowing, broadening, splitting or rejecting the current wording?

## Evidence levels

Each provenance file distinguishes:

- **Primary source** — canonical text, legal instrument, historical source or original philosopher where practical.
- **Scholarly interpretation** — serious secondary work used to avoid naive or decontextualised readings.
- **Historical practice** — what institutions and communities actually did, which may conflict with ideals.
- **Modern reconstruction** — later interpretations that recover, revise or extend an older tradition.
- **Project synthesis** — our own conclusion. This is never presented as if the underlying tradition itself said it.

## Status vocabulary

| Status | Meaning |
|---|---|
| Strong support | A close analogue is central or repeatedly defended. |
| Partial support | Important overlap exists, but scope or grounding differs materially. |
| Tension | The tradition contains both supporting and conflicting elements. |
| Contradiction | Important source/practice directly conflicts with the Moral Code rule. |
| Not native | The exact concept is not naturally expressed in that tradition; forcing it into the framework would distort the source. |
| Unresolved | Evidence or interpretation is insufficient or contested. |

## Anti-cherry-picking rule

A tradition may not be counted as supporting a Moral Code principle merely because one attractive quotation can be found.

Each file must deliberately seek:

- counter-texts,
- hierarchy and exclusion,
- historical application,
- minority interpretations,
- and scholarship critical of harmonising readings.

The project is interested in principles that survive criticism, not quotations that decorate conclusions already reached.

## Metaphysical neutrality

The Moral Code may inherit a moral principle without inheriting its supernatural or metaphysical justification.

For example, traditions may ground dignity in:

- creation in the image of God,
- universal divine law,
- Buddha-nature or the capacity for suffering,
- the jiva,
- Oneness,
- shared humanity,
- rational agency,
- social relationship,
- or political agreement.

The common layer must state only what remains defensible when those incompatible metaphysical explanations are not imposed on everybody else.

## Difference between universality and convergence

The project should prefer the language **convergent moral core** to claims that every principle is literally universal across all texts and cultures.

A principle can be retained when:

- it arises independently from multiple traditions,
- it survives major objections better than rival rules,
- it is required to prevent known forms of domination or atrocity,
- and its application can be justified without demanding acceptance of one contested worldview.

This is a stronger and more honest standard than pretending unanimous historical agreement.

## Versioning

Provenance is evidence for constitutional change; it is not itself the constitution.

Files in this directory may recommend changes to `constitution/MORAL_CORE.md`. No recommendation becomes constitutional until adopted through the amendment/governance process.
