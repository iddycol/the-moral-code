# Governance Principles

- **G-01 No founder infallibility.** Founders and maintainers have no exemption.
- **G-02 Amendments require reasons.** State the problem, evidence, affected rules, Crucible impact and objections.
- **G-03 Hard changes require stronger review.** Moral-floor and power changes require heightened scrutiny.
- **G-04 Preserve dissent.** Serious objections remain visible even when an amendment passes.
- **G-05 No hidden constitutional change.** Implementations identify the exact constitutional version used.
- **G-06 Regression before release.** Material changes run the full Crucible.
- **G-07 Open provenance.** Important conclusions do not exist only in private chat or undocumented model output.
- **G-08 Machine agreement is evidence, not authority.**
- **G-09 Human popularity is evidence, not authority.**
- **G-10 The Code remains revisable.** Revisability is mandatory; arbitrary mutability is not.
